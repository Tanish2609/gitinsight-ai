# GitInsight AI

GitInsight AI is an AI-powered GitHub repository reviewer built using LangGraph and Ollama.

## 🚀 Current Progress

### Completed

- Repository cloning using GitPython
- Source file discovery
- File filtering (ignores venv, .git, node_modules, etc.)
- LangGraph workflow setup
- Repository parser
- File selector
- Conditional routing skeleton

## Current Workflow

```text
START
   │
Clone Repository
   │
Parse Repository
   │
Select File
   │
END
```

## Tech Stack

- Python
- LangGraph
- LangChain
- Ollama
- GitPython
